Repositorio público de Mariana Avila Arelio

El tablero permite explorar los principales indicadores de siniestralidad y cotizar primas. Entre sus principales funciones tenemos: segmentar por cobertura, sexo, uso del vehículo, combustible, edad; KPIs que muestran la exposición, el número de siniestros, la frecuencia, la severidad y la prima pura; y el cálculo de primas. 

¿Cómo ejecutar el tablero de manera local?
1. Abrir la terminal
2. Acceder a la carpeta que contiene el tablero (cd tablero-seguros)
3. Ejecutar desde la terminal con streamlit run (ruta del tablero)
4. Abrir el resultado en el navegador (default) o desde VSC
